# InfraWatch: One-page next-steps summary

## What InfraWatch does

InfraWatch puts infrastructure project information in one website.

People can search for projects, view project details and maps, report problems with photos or videos, track their reports, and ask ANIA simple questions.

Government staff can view project statistics, find delayed projects, review reports, and monitor data problems.

## What already works

- Searchable project records
- Public project pages and statistics
- Management dashboard
- Maps using official project coordinates
- Citizen reports with photos, videos, and location information
- Citizen report tracking
- ANIA project-information assistant
- Staff pages for reports, feedback, users, data checks, and update history

## What partly works

- GeoVideo works for submitting and reviewing evidence, but public approval and formal field validation are unfinished.
- The project map works, but some filters, colors, labels, and sample map layers need correction.
- Delayed and at-risk project warnings work, but there is no complete staff action and follow-up record.
- Citizen reporting works for signed-in users, but the anonymous option is misleading and the assignment and closing process is incomplete.
- Different infrastructure types can be stored, but each type still needs its own approved monitoring rules.

## What has not been built yet

- SMS Connect
- CSV and JSON data downloads
- Automatic report assignment and routing
- Official response deadlines
- Overdue-report escalation

## Most urgent problems

1. Project data has not updated successfully since August 11, 2026. Ten update attempts have failed.
2. Internal report notes may be visible too widely through audit records.
3. Report status changes are not yet controlled by a strict process.
4. Some map layers are sample shapes, not real GeoServer data.
5. The map has incorrect filters, colors, and an old FMR Watch label.
6. The latest dashboard and security work is not yet committed, so the presentation copy must be checked carefully.

## What to build next

1. Fix project data updating and failure alerts.
2. Protect report privacy and history.
3. Assign every report to a responsible person or office.
4. Add BAFE-approved response deadlines and overdue warnings.
5. Notify citizens when their report changes.
6. Add safe CSV and JSON downloads.
7. Correct and speed up the project map.
8. Add a project watchlist with assigned actions.
9. Start a small SMS pilot.
10. Add separate approved monitoring rules for each infrastructure type.

## What to say during the presentation

> "InfraWatch already provides project search, public information, maps, citizen reporting, management analytics, and AI-assisted project questions. The next phase will improve data updating and complete report assignment, response deadlines, escalation, public data downloads, and SMS notifications."

## What not to claim

Do not say that:

- The data is real-time.
- The system shows actual money spent.
- Every project is on the map.
- GPS evidence cannot be faked.
- SMS and data downloads already work.
- Reports are already assigned and escalated automatically.
- Official BAFE response deadlines are already active.
