# How INFRA Watch writes Tagalog

The Tagalog on the public site is everyday Tagalog, the way people talk and text, not
textbook or legal Tagalog. Raray asked for Tagalog that is "hindi masyadong malalim at
hindi masyadong pormal".

## Voice

- Talk to one person with **ka / mo / iyo**, not *kayo / ninyo / inyo*.
- Leave out **po / opo** in labels and buttons. A short "po" is fine in a thank-you or
  apology line, but not elsewhere.
- Use short sentences. One idea per sentence.
- Use Taglish where people already say the English word: project, report, status, map,
  filter, budget, email, upload, submit, download, link, photo, video, online, update,
  barangay, region, province, municipality (or "bayan"), contractor, farmer group, live.

## Prefer the everyday word

| Avoid (malalim / pormal)        | Use                               |
| ------------------------------- | --------------------------------- |
| Galugarin                       | Tingnan / Silipin                 |
| Pamumuhunan                     | Gastos / Pondo / Halaga           |
| Isumite / Ipasa                 | I-submit / Ipadala                |
| Pakisubukang muli               | Subukan ulit                      |
| Magpatuloy                      | Tuloy / Sige                      |
| Linisin (the filters)           | I-clear / Alisin                  |
| Kasalukuyang isinasagawa        | Ginagawa pa                       |
| Naisakatuparan / Nakumpleto     | Tapos na                          |
| Mamamayan (in labels)           | Tao / publiko (or keep "citizen") |
| Impormasyon ukol sa             | Info tungkol sa                   |
| Paumanhin                       | Sorry / Pasensya na               |
| Kaukulang tanggapan             | Opisinang in-charge               |

## Keep as is

- Names: INFRA Watch, InfraWatch, BAFE, DA, ABEMIS, ARIA, program names (FMR, SAAD...),
  place names, facility and commodity names that come from the data.
- Placeholders like `{count}` or `{name}`: same names, same number of them.
- Numbers, pesos and dates: formatted the same way in both languages.
- Legal pages (Terms, Privacy Notice, Data Deletion) stay in English until a reviewed
  translation exists.

## Examples

- "Explore Projects" → "Tingnan ang mga Project"
- "Submit report" → "I-submit ang report"
- "Something went wrong. Please try again." → "May nagka-problema. Subukan ulit."
- "No projects match these filters." → "Walang project na tugma sa mga filter na ito."
- "Loading…" → "Naglo-load…"
